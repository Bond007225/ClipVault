How to set it as your lock screen
  1. Pick the 3 s (Live Photo) loop and export the video, then save it to Photos (Share → Save Video).
  2. iOS only animates lock screens from a Live Photo, so convert the video with a video-to-Live-Photo app from the App Store.
  3. Go to Settings → Wallpaper → Add New Wallpaper → Photos and pick the Live Photo.
  4. Make sure the Live Photo button is on. iOS plays the animation once each time you wake the phone, then shows the still.
  5. If your converter lets you pick the key photo, choose the first frame. Play-once clips end on that frame, so the animation settles into the still without a jump.
